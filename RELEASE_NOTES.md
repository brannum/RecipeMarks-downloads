# RecipeMarks 2.0.1 — Linux

Public Linux desktop installers for **x86-64 / amd64**.

## Included

- Local recipe library with URL import, recipe photos, cooking views, and timers.
- Grocery and pantry lists, meal planning, printing, and portable backup/restore.
- Updated Browse layout for desktop windows.
- Bundled desktop runtime; no separate Python installation required.
- Free Local use without an account; hosted Plus services are not for sale in this release.

## Downloads

- `RecipeMarks-2.0.1-linux-x86_64.AppImage` — portable app.
- `RecipeMarks-2.0.1-linux-amd64.deb` — Ubuntu/Debian-based installation.
- `SHA256SUMS` — checksums for the exact release files.

[Installation and update instructions](https://github.com/brannum/RecipeMarks-downloads/blob/main/INSTALL.md).

Keep a portable backup before upgrading or switching package formats. Snap and direct packages may use separate local profiles. This release does not include ARM64 or 32-bit Linux installers.
